# 足球奇域模拟器（Football Qiyu Simulator）

基于原神「千星奇域」奇域项目的**事件优先级排序**工具：用状态逻辑图描述球权 / 位置 / 控制 / 血量四个逻辑域，通过图粘合（glue）、复合（compose）、超边（hyperedge）构造总状态逻辑超图，并基于 BFS 事件搜索树计算事件优先级、给出参数平衡建议。

## 优先级语义

- 短时间内事件队列中出现**冲突事件**时，用优先级决定**哪个事件只执行一次**（其余被抑制）。
- 优先级的目的：**避免全局状态陷入短的死循环，尽量处于大的循环中**。
- 因此算法不是"层数越深优先级越高"，而是：**位于"起点（无球）→ 主大循环"路径上、以及主大循环上的事件优先级高；困在短环（长度 < 4）内的事件被惩罚**。
- 同分决胜：手动基础优先级 → 内置默认序（传＞掉＞射＞蓄力条更新＞拿＞激活射门技能＞关闭射门技能）。

## 图结构

- **个体状态逻辑图**：节点 = 状态（无球 / 持球 / 蓄力 / 射门激活…），边 = 事件（带条件与参数：基础优先级、冷却、结构权重）。
- **粘合（glue）**：同名状态节点跨实体合并；如断球与传球共享"持球→无球"变化。传球经由**临时虚拟队友实体**（队内拿球状态）转接，队友未接住则转为队外自由态被随机争抢。
- **复合（compose）**：状态叠加（图替换式），球逻辑 × 位置逻辑 × 控制逻辑 × 血量逻辑互不影响，各域独立 BFS 后合并排名。
- **超边**：多实体联合事件（如 A 传球给 B 同时改写双方与球）。

## 功能

1. **图编辑**：可视化拖拽编辑四个逻辑域的状态图（双击新建状态、连线模式创建事件、点击边编辑条件/参数/技能挂载）。
2. **总超图**：跨域同名状态自动粘合后的分层可视化（按 BFS 层展开），含粘合记录与超边清单。
3. **优先级计算**：每逻辑域独立 BFS（起点=无球）→ Tarjan SCC 主循环识别 → 路径分 × 短环惩罚 × 结构权重 + α·手动分；输出全量排名与同刻冲突裁决预览。
4. **参数建议**：伤害基准 / 血量上限 / 掉球阈值 / 位移基准距离滑杆，即时重算；短环破除、流量引导、参数平衡三类建议；可记录基线对比名次变化。
5. **技能模板**：伤害事件模板与位移事件模板自由设计（未接入游戏）。
6. **多方案隔离存储**：localStorage 持久化 + JSON 导入导出；默认示例 3v3（6 玩家 + 1 球）。

## 开发

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

技术栈：React + TypeScript + Vite + Tailwind CSS。
