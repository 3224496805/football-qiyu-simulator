# 足球奇域模拟器（Football Qiyu Simulator）

面向原神「千星奇域」UGC 创作的**奇域事件逻辑模拟器**：用「事件库」描述关卡里每个实体的状态机，自动生成各维度的状态逻辑图和代表整个关卡精准状态的**总超图**，并提供优先级分析、动态模拟和 AI 辅助设计。

线上版：<https://3224496805.github.io/football-qiyu-simulator/>

## 核心概念（对齐千星沙箱官方创作体系）

- **事件库是唯一数据源**。每张事件卡写清：归属实体、触发方式、监听、前提状态、状态变化、数值效果。逻辑图和总超图都是事件库的派生展示，改事件库它们自动更新。
- **主动事件** = 从客户端发出（玩家按键操作）；**被动事件** = 检测到状态变化后触发（≈ 官方「当……时」节点）。
- **监听** = 信号全局可达：被动事件可声明监听哪些事件（按名字认）；不填监听 = 持续检测，每次判定都看前提。
- **前提状态** = 事件判定前必须（或必须不）处于的状态，可跨维度组合。
- **实体铁律**：一条事件只属于一个实体（角色 / 球 / 球门），只能改自己维度的状态；跨实体联动必须拆成「对方监听本事件后自己改」的另一条事件。
- **单维度逻辑图** = 事件库里落在某一维度上的状态变化画成的图；**总超图** = 全部维度合并、同名状态自动粘合，代表整个奇域关卡的精准状态（只读）。

## 功能

1. **编排**：左栏事件库（搜索/筛选/新建/复制/删除）+ 中栏画布（单维度逻辑图 / 总超图）+ 右栏检查器（事件详情 / 状态详情 / 方案体检）。画布支持直接在图上双击加状态、连线建事件、删除变化——全部写回事件库。
2. **优先级排名**：在总超图上计算 —— 最终分 = 0.4 × 稳态概率（长期运行下状态被停留的概率）+ 0.3 × 主循环路径分（Tarjan 强连通分量识别主循环）+ 0.3 × 手动微调；落在 2~3 状态短环里的变化 × 0.3 惩罚。每行可展开看分数拆解，拒绝黑箱。
3. **动态模拟**：事件驱动的虚拟比赛（开始/暂停/单步/倍速），8 个实体状态表 + 全程事件日志；蓄力锁、同名抢占每拍限一次、反应优先结算等规则保证模拟贴近设计意图；球门进满 3 球自动结算。
4. **AI 生成事件**：直连 Kimi API（密钥只存在本浏览器）或手动粘贴 JSON，生成的事件经完整校验后入库（实体铁律、监听存在性、维度存在性、重名、空事件等都会检查并中文报错）。
5. **旧档一键转换**：v14 及以前的「逻辑图直存」存档可一键转换为事件库格式（同名边合并成一条事件），附中文转换报告，旧数据原样保留。
6. **方案管理**：多方案本地存储、JSON 导入导出。

## 本地开发

```bash
npm install
npm run dev      # 本地开发服务器
npm run build    # 产出 dist/
```

技术栈：React + TypeScript + Vite + Tailwind CSS。

## 自检与部署

```bash
# 自检（无需启动网页）：打包后在 Node 里跑断言
node scripts/bundle-tool.mjs scripts/smoke2.ts && node scripts/.smoke2.bundle.mjs   # 派生图
node scripts/bundle-tool.mjs scripts/smoke3.ts && node scripts/.smoke3.bundle.mjs   # 图编辑写回 + 旧档转换
node scripts/bundle-tool.mjs scripts/smoke4.ts && node scripts/.smoke4.bundle.mjs   # 优先级 + 动态模拟
node scripts/bundle-tool.mjs scripts/smoke5.ts && node scripts/.smoke5.bundle.mjs   # AI 导入校验

python scripts/push_main.py      # 推送源码到 main 分支
npm run build && python scripts/deploy_pages.py   # 发布 dist/ 到 GitHub Pages
```
